出力機能の対応範囲と Agent の効果

AI経営ナビアプリ／2026-09-16／前提：Amazon Bedrock（東京・Claude Opus 4.8）、Agent なし（1往復でアプリが処理を確定）
現在の仕組み（Agent なし）利用者の文面から出力の種類をアプリが規則で決め、AI は「表の値」「グラフの仕様」「図の要素と関係」の整理を1回だけ行う。描画・ファイル化はアプリの固定処理。AI が結果を見直したり、道具を呼んだりする工程は無い。
Agent がある場合AI が出力結果を確認し、修正・再試行・追加の検索を自律的に繰り返す構成。クライアントのリスク整理では「外部送信の判断を AI に委ねない」が条件のため、Agent を入れる場合も道具は Bedrock 内で閉じたもの（ファイル生成・社内検索）に限る。
機能現在の仕様でできることAgent なしの限界Agent があるとプラスになる点
1. Word／PDF 出力 対応済み
  • 直前の回答（Markdown）を見出し・箇条書き・表・太字ごと変換。AI を呼ばず即時
  • PDF は日本語フォント埋め込み。「〜を整理して Word にして」の一括依頼も可
  • 体裁は固定テンプレ1種（社内様式・目次・図の差し込みなし）
  • 内容の点検なし。回答の誤りや不足はそのまま文書に入る
  • 変換に失敗すると通知のみ。修正は人が再依頼
  • 出力前の自己点検（数値と出典の照合、体裁の乱れ）と自動修正
  • 社内テンプレの適用、複数案の作成と選択を対話で反復
  • 失敗時の自動リトライ
2. Excel／CSV 出力 対応済み
  • 回答内の表はそのまま、無ければ AI が1回で表に整理し、アプリが xlsx／csv を生成
  • 数値は数値型、CSV は Excel で文字化けしない形式
  • 1表・1シートのみ。数式・書式・集計列は付かない
  • AI の整理が回答文と食い違っても検出しない（確認は人）
  • JSON 不正は1回だけ再試行し、だめなら通知で終了
  • 生成後に元の回答・資料と突合し、差異を自動修正
  • 複数シート、集計・検算列、既存 Excel への追記
  • 不足データを社内資料から追加検索して補完
3. グラフ描画 対応済み
  • 7種類（縦棒・横棒・積み上げ・折れ線・面・円・散布）。文面の指定が無ければ AI が内容から選択
  • AI は軸と系列の仕様だけを作り、アプリが描画（PNG）。数値が無ければその旨を通知
  • 種類は固定。2軸・複合グラフ・ヒートマップは不可
  • 単位の混在やスケールの妥当性を検証しない
  • ラベルの重なり等は描画結果を見て人が再依頼
  • 描いた画像を AI が確認し、重なり・スケール・種類を自動で直す
  • 複数の見せ方を比較提示
  • データ不足時に社内データを検索して系列を補う
4. PPTX ポンチ絵／Mermaid 対応済み
  • AI が要素と関係を整理し、アプリが配置・作図。PPTX は PowerPoint で編集可、Mermaid はコード・.mmd・PNG
  • 流れ図（左→右）・関係図・階層図の3型。要素12・関係20まで
  • 自動配置のため線の交差や重なりが残ることがある
  • 1枚のみ。複数スライド・社内テンプレ・アイコンは不可。Mermaid は flowchart のみ
  • 要素の抜け・関係の誤りは点検しない
  • 配置を見て再レイアウト、複数スライドの構成、テンプレ適用
  • 回答との整合（要素の抜け）を点検して補正
  • シーケンス図・ガントなど Mermaid の種類を内容に応じて選択
5. 画像生成 未対応
  • Claude は画像を生成しない。Bedrock の画像モデル（Amazon Nova Canvas＝東京在庫あり・旧世代で EOL 2026-09-30 予定／Stability AI＝東京提供は要確認）を別経路（bedrock-runtime＋IAM）で追加すれば可
  • GPT Image 2 は Bedrock 非対応。同等品質は Bedrock の外になる
  • 実装しても「プロンプト1回→1枚」。出来栄えの判定と再生成は人
  • 日本語文字入りの図版は精度が低い
  • 生成→評価→プロンプト修正の反復、複数案の比較
  • ただし品質の上限はモデル依存で、Agent では埋まらない

共通

観点Agent なし（現在）Agent あり
品質チェック行わない。出力ファイルは回答の原文どおり。確認は利用者AI が出力を読み返して自己点検・修正。ただし検証の基準（正解データ）が無い項目は限界が残る
エラー対応失敗はエラー通知（原因つき）で終わり、再依頼は人。JSON 不正のみ1回自動再試行原因に応じて依頼を言い換え・分割して自動リトライ
安全性AI が決めるのは中身の整理だけ。外部送信・実行は無く、リスク整理どおり道具の呼び出しが増えるぶん、道具を Bedrock 内・社内に限定し、実行回数を上限で縛る設計が必要
応答時間・費用1往復（Word／PDF は AI 呼び出しなし、他は AI 1回）反復のぶん時間と Token が数倍になる
出典：Bedrock の画像モデルは AWS モデルカタログ（2026-09）、GPT Image 2 の Bedrock 非対応は OpenAI 公式「OpenAI models in Amazon Bedrock」。
